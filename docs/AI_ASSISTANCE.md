# AI assistance statement

Generative AI tools were used in this project to assist with code drafting,
debugging, documentation organization and language refinement.

The study question, biological scope, inclusion and exclusion decisions,
interpretation of evidence, validation rules and final scientific conclusions
were reviewed and approved by the author. All computational outputs reported
from this repository are reproduced by the deposited pipeline and checked
against locked reference results.

No AI system is listed as an author. Any associated manuscript will include a
disclosure worded according to the target venue's policy.
